2. 本アプリの基本方針

本アプリは、写真・動画の撮影、編集、書き出しをお使いの端末の中だけで処理します。本バージョンでは、写真・動画を当方のサーバーや第三者のサーバーへ送信する機能はありません。AI による生成・編集機能も本バージョンには含まれていません。

3. 写真・動画

  • 撮影した写真・動画、写真ライブラリから選択した写真・動画、編集の設定、処理結果、編集履歴は、本アプリ専用の端末内領域に保存されます。
  • 写真ライブラリへの保存や他のアプリへの共有は、利用者の操作に基づいてのみ行われます。
  • ウィジェットに写真を表示する場合、本アプリとウィジェット拡張は同じ端末内の共有領域（App Group）を使用し、縮小したサムネイルと撮影日時・撮影枚数などの集計値を保存します。この共有領域も端末外には送信されません。
  • カメラ、マイク、写真ライブラリへのアクセスは、それぞれ撮影、音声付き動画の録画、写真の読み込み・保存のためにのみ使用します。アクセス許可は iOS の設定からいつでも変更できます。
  • 写真に写っている人物や、写真に含まれる撮影情報（位置情報など）の取り扱いには、共有前にご注意ください。
  • AI 編集（任意機能）：ライブラリの写真で「AI編集」を使い、利用者が「生成する」を押した場合に限り、その写真（最長辺 1536 px 以下に縮小したもの）と選択した編集内容（消す・雰囲気・引きにする、選択した範囲や倍率）が、当方のサーバー（Supabase 上の中継機能）を経由して OpenAI, L.L.C. の画像編集 API に送信されます。初回利用前に、アプリ内で送信内容を表示して明示的な同意を求めます。同意はアプリ内でいつでも取り消せます。
  • AI 編集の利用にはログインが必要です。当方のサーバーは写真を保存せず、ログインアカウントの識別子・利用日時・編集の種類・結果の成否のみを利用回数の管理と不正利用の防止のために記録します。生成結果は元写真を上書きせず、利用者が保存操作をした場合にのみ写真ライブラリに保存されます。
  • OpenAI は API に送信された画像を AI の学習に使用せず、不正利用の監視のために最長 30 日間保持した後に削除します（OpenAI の API データ利用ポリシーに基づきます）。

4. アカウント情報

本アプリのログインには、認証サービス「Clerk」（Clerk, Inc.）を利用しています。ログイン方法として Apple でサインイン、Google アカウント、メールアドレスを選択できます。

Clerk が当方に代わって取り扱う情報:

  • メールアドレス
  • アカウント識別子（Clerk が発行するユーザー ID、セッション情報）
  • 選択したログイン方法に応じて Apple または Google から提供される氏名などのプロフィール情報
  • ログインの安全確保および不正利用防止のための技術情報（IP アドレス、端末の種類、最終利用日時など）

利用目的: ログイン、アカウントの識別と管理、不正利用の防止、お問い合わせへの対応。

本アプリ自体は、画面表示のためにメールアドレスを読み取るほかは、アカウント情報を独自のサーバーに保存しません。Clerk におけるデータの取り扱いは Clerk のプライバシーポリシーおよびデータ処理契約に従います。

5. 購入・サブスクリプション

  • アプリ内購入の決済は Apple（App Store）が処理します。当方はクレジットカード番号などの支払い情報を取得しません。
  • 本アプリは、Apple の StoreKit を通じて購入状態を端末上で確認し、対象のアプリアイコンの利用権を判定します。購入情報を当方のサーバーへ送信することはありません。
  • 購入の権利は App Store の Apple Account に紐づきます。本アプリのログインアカウントを切り替えたり削除しても、Apple との契約は解約されず、購入が移動することもありません。

6. 収集しない情報

本アプリは、位置情報、連絡先、健康情報、支払情報を収集しません。広告 SDK や分析 SDK を組み込んでおらず、利用者を他社のアプリやウェブサイトを横断して追跡（トラッキング）しません。

7. 保存期間と削除

  • 端末内の写真・動画・編集データは、利用者が本アプリ内で削除するか、本アプリをアンインストールするまで端末に残ります。
  • アカウントの削除は、本アプリの設定画面にある「アカウント管理・削除」から開始できます。削除が完了すると、Clerk に保存されたアカウント情報は Clerk の手順に従って消去されます。認証サービス提供者のバックアップからは、削除後、合理的な期間内（最長90日程度）に消去されます。
  • アカウントを削除しても、端末内の写真・動画は自動的には削除されません。写真を消す場合は、本アプリ内で削除するか、本アプリをアンインストールしてください。写真ライブラリに書き出した写真は、写真アプリから別途削除する必要があります。
  • 同じ端末では、別のアカウントでログインしても同じ端末内の写真が表示されます。端末を他の方と共有する場合はご注意ください。
  • サブスクリプションの解約は Apple のサブスクリプション管理から行ってください。アカウント削除では解約されません。
  • AI 編集の利用記録（アカウント識別子・日時・編集の種類・成否）は、利用回数の管理のため最長 13 か月保存した後に削除します。アカウント削除後は、当該識別子に紐づく記録を合理的な期間内に削除します。

8. 第三者への提供

当方は、利用者の情報を第三者に販売しません。以下の場合を除き、第三者へ提供しません。

  • 上記 4 および 5 に記載した Clerk、Apple、および利用者が選択したログイン提供者（Apple、Google）への必要な範囲での提供
  • 上記 3 に記載した AI 編集で、利用者の操作と同意に基づき、当方のサーバー基盤（Supabase Inc.）を経由して OpenAI, L.L.C. へ写真と編集内容を送信する場合
  • 法令に基づく場合
  • 利用者の同意がある場合

9. 安全管理

本アプリは、ログインのセッション情報を iOS のキーチェーンなどの保護された領域に保存し、通信は暗号化された経路（HTTPS）で行います。写真・動画は端末外へ送信されないため、端末のパスコード等による保護をお勧めします。
